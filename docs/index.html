About

FakeProt generates synthetic protein families by simulating protein evolution along a random phylogenetic tree. Each branch evolves under the WAG substitution model with gamma-distributed site rates and optional physicochemical constraints on amino acid identity.

The output includes all sequences (including ancestral nodes), a gene tree, a species cladogram, ortholog group assignments, and a per-column stereochemistry report — everything you need to benchmark aligners, tree reconstruction methods, and ortholog detection tools against ground truth.

The simulation runs entirely in your browser via Pyodide. No data is sent to any server. First load takes ~30 s while Python packages are downloaded and compiled; subsequent loads are fast thanks to browser caching.
