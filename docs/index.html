About FakeProt

FakeProt generates synthetic protein families by simulating sequence evolution along a random phylogeny. Substitutions follow the WAG substitution model (Whelan & Goldman, 2001) with gamma-distributed among-site variation rates and probabilistic physicochemical constraints. Insertions and deletions are also introduced stochastically.

Outputs include a multiple sequence alignment (MSA), a gene tree with branch lengths, a species cladogram, ortholog group assignments, and a per-column report of physicochemical group frequencies. FakeProt is primarily designed for educational purposes, to explore how sequence divergence, site-rate variation, and gene duplication shape protein families. Because the true evolutionary history, sequence ancestral states, and orthology relationships are known, FakeProt is suitable for benchmarking alignment methods, phylogenetic reconstruction, ancestral sequence inference, and ortholog detection tools.

Runs entirely in the browser via Pyodide. No data are uploaded to any server. The first load downloads and installs required Python packages; subsequent loads use the browser cache.
