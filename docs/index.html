About FakeProt

FakeProt simulates synthetic protein families with known evolutionary histories. Starting from a single ancestral protein, it builds species and gene trees through speciation and occasional gene duplication.

Evolution is modelled using WAG substitution, gamma-distributed site rates, stochastic indels, and physicochemical constraints. See the README for the full generative model and references.

Outputs include alignments, trees, ortholog-group assignments, physicochemical summaries, and reproducibility metadata. Because the true history is known, the data are useful for benchmarking evolutionary-analysis methods such as multiple-sequence aligners, tree inference, orthology pipelines, and ancestral-state reconstruction, as well as for educational purposes.

Runs locally in the browser via Pyodide. No data are uploaded. The first execution downloads Python packages; later executions use the browser cache.
