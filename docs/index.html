FakeProt generates synthetic protein families by simulating protein evolution along a random phylogenetic tree. Each branch evolves under the WAG substitution model with gamma-distributed site rates and probabilistic physicochemical constraints on amino acid identity.

Output includes all sequences (including ancestral nodes), a gene tree, a species cladogram, ortholog group assignments, and a per-column physicochemical group report — intended for benchmarking multiple sequence aligners, phylogenetic reconstruction methods, and ortholog detection tools against ground truth.

The simulation runs in-browser via Pyodide. No data are transmitted to any server. First load may take a few seconds for package download and compilation; subsequent loads are served from the browser cache.
